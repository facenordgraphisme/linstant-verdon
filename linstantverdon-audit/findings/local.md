## NAP Consistency — CRITICAL ISSUE

**NAP = Name, Address, Phone — must be identical everywhere.**

| Source | Address listed |
|--------|---------------|
| Website (all pages) | Place de l'église, 04120 Castellane |
| Verdon Tourisme | 395 Haut Bourras, 04120 La Palud-sur-Verdon |
| Provence-Alpes-Côte d'Azur Tourism | La Palud-sur-Verdon |
| Tourisme Alpes Haute-Provence | La Palud-sur-Verdon |
| TripAdvisor | La Palud-sur-Verdon |

**Two different addresses are being used:**
1. **Place de l'église, 04120 Castellane** — on the website
2. **395 Haut Bourras, 04120 La Palud-sur-Verdon** — in all external directories

This is a **critical local SEO problem**. Google cross-references NAP across sources to verify business identity. Inconsistent NAP:
- Reduces local pack ranking confidence
- May prevent the Knowledge Panel from appearing correctly
- Confuses customers trying to find you

**Fix:** Decide on ONE canonical address and update it everywhere — the website AND all directory listings. If the business moved, update all citations. If both are valid locations, clarify (e.g., meeting point vs. main office).

## Review Integration on Website

**Critical gap:** The website has **no customer review integration** despite strong TripAdvisor presence.

With 54 reviews and a #3 ranking, L'Instant Verdon has significant social proof that should be featured prominently:

**Recommendations:**
1. Add a "Nos Avis" section on the homepage featuring 3-5 top reviews with names, dates, and TripAdvisor attribution
2. Display aggregate rating (e.g., "4.8/5 — 54 avis sur TripAdvisor")
3. Add AggregateRating schema to boost rich result eligibility
4. Embed a TripAdvisor widget or manual review carousel
5. Add a CTA: "Lire tous nos avis → TripAdvisor"

The site serves the Gorges du Verdon area broadly — activities are conducted in multiple canyons (Clue d'Artuby, Balène, Saint-Auban, Bas-Jabron, Main-morte, Carelle viewpoint). For local SEO:
